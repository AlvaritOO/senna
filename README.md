# SennaWeb

Sitio web de **Senna Apart Hotel** — apartamentos con servicio hotelero en el
Barrio El Tenis, Rancagua (Oficial Carlos María O'Carrol 022).

## Qué hay aquí

- **`sitio-web/`** — el sitio, y lo que se mantiene. Una sola página estática
  (HTML/CSS/JS, sin build). Ver [`sitio-web/README.md`](sitio-web/README.md).
- `senna-cadena-hotelera.md`, `descripciones-productos.md` — narrativa de marca
  y copys originales.
- `SennaOcarrolRancagua/`, `SennaComercioRequinoa/` — fotos originales sin
  procesar. **No borrar: es el material de origen.**

## Alcance

El sitio cubre **solo la sede de Barrio El Tenis**. La sede de Requínoa se
retiró del sitio (páginas, enlaces y menciones), pero su material fotográfico
se conserva por si vuelve a entrar en alcance.
